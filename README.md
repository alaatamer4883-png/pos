# 📱 منظومة الكاشير وإدارة محافظ فودافون كاش الـ 18 المتكاملة
## Vodafone Cashier & 18-Line Multi-Wallet Management System (Crimson Console)

منظومة ويب متكاملة وعصرية (Modern Single Page Web Application) مصممة خصيصاً لنقاط البيع (POS)، فروع ووكلاء فودافون كاش، وكاشير المحافظ المتعددة. مبنية بالكامل باستخدام **HTML5, CSS3, JavaScript (ES Modules)** ومربوطة مباشرة بقاعدة بيانات **Firebase Firestore**.

---

### ✨ أبرز مميزات المنظومة:

#### 1. 📊 لوحة التحكم الشاملة (Dashboard):
* **نظرة عامة متقدمة:** إجمالي السيولة المجمعة لكافة الـ 18 خط لحظياً (Total Aggregated Float).
* **مؤشرات الأداء اللحظية (KPIs):** حجم المعاملات اليومية، عدد العمليات المكتملة، العمولات وصافي الأرباح، وحالة الخطوط التشغيلية.
* **بطاقة مخصصة مستقلة لمبيعات اليوم (Today's Sales Spotlight):** تبرز التدفقات النقدية الداخلة والخارجة وصافي الدرج مع زر للانتقال لشاشة المبيعات المستقلة.
* **شبكة الـ 18 خط المباشرة (18-Line Live Grid):** بطاقات تفاعلية تتيح معرفة الرصيد، نسبة استهلاك الحد اليومي، النسخ السريع، والانتقال لبروفايل الخط.

#### 2. 📱 إدارة الـ 18 محفظة وبروفايل الخط المنفصل (Isolated Line Profiles):
* **شاشة مستقلة تماماً لكل خط من الـ 18 خط:**
  * رقم الخط وشريحة الـ SIM وحالة التغطية والسيولة.
  * عداد الرصيد اللحظي المتاح.
  * **عداد الحد اليومي للإرسال (Daily Send Limit):** سقف 60,000 ج.م مع شريط تقدم ونسبة الاستهلاك.
  * **عداد الحد الشهري للإرسال (Monthly Send Limit):** سقف 200,000 ج.م.
  * **عداد حد الاستقبال اليومي (Daily Receive Limit):** سقف 60,000 ج.م.
  * **نموذج تنفيذ عمليات مباشر للخط:** إيداع (كاش إن)، سحب (كاش أوت)، أو تحويل لمستفيد، مع أزرار المبالغ السريعة (500، 1000، 2000، 5000 ج.م).
  * **دفتر حسابات مخصص للخط:** جدول عمليات حصري للخط المحدد فقط لمطابقة الحركات والرسائل.

#### 3. 💰 شاشة مبيعات وعمليات اليوم المستقلة (Today's Sales Ledger):
* شاشة منفصلة تماماً ومحمية من التداخل لعرض وتدقيق مبيعات الوردية.
* فلترة حسب نوع العملية (إيداع / سحب / تحويل).
* فلترة حسب خط المحفظة (الـ 18 خط أو خط محدد).
* بحث فوري برقم هاتف العميل أو رقم المرجع.
* رسم بياني تفاعلي لكثافة وسرعة العمليات على مدار ساعات اليوم (Hourly Velocity).
* إمكانية طباعة إيصال حراري فوري (80mm Thermal Receipt) لأي معاملة.

#### 4. 📷 المسح الضوئي الذكي (QR & Barcode Scanner):
* ماسح ضوئي مدمج يدعم الكاميرا الحية (Webcam أو كاميرا الموبايل الخلفية).
* مسح باركود الإيصالات الورقية وأكواد تطبيق "أنا فودافون".
* إمكانية مسح صورة إيصال محفوظة (File Upload Scanner).
* إدخال واستعلام يدوي سريع بواسطة لوحة المفاتيح.
* **التوجيه الذكي للمحافظ (Smart Line Routing):** يقترح النظام تلقائياً أفضل خط محفظة يمتلك سيولة وحدود كافية لتنفيذ العملية.

#### 5. 🗂️ خزنة الإيصالات والاسكرينات ("اسكرينه لوحدها" - Screenshots Proof Vault):
* شاشة مستقلة لحفظ وتدقيق اسكرينات تحويلات العملاء.
* رفع بالسحب والإفلات أو اختيار الملفات.
* **ميزة اللصق المباشر من الحافظة (`Ctrl + V`):** يستطيع الكاشير نسخ أي اسكرينة ولصقها مباشرة في الشاشة دون الحاجة لحفظها كملف!
* فحص مكبر للاسكرينة ومحاكاة استخراج بيانات التحويل (OCR) ومطابقتها واعتمادها.

#### 6. 📖 دليل الهواتف والنسخ السريع (Quick Phone Directory & USSD):
* قائمة بأرقام الـ 18 خط بخط واضح وكبير مع زر نسخ فوري بنقرة واحدة وتنبيه "تم النسخ!".
* أهم أكواد فودافون كاش السريعة (USSD) للتحويل والاستعلام وسحب ATM.

#### 7. 🧮 تقفيل الدرج وتقرير نهاية الوردية (Z-Report & Drawer Closing):
* حاسبة جرد فئات النقدية الورقية (200، 100، 50، 20، 10 جنيه).
* حساب الفارق بين النقدية الفعلية والنقدية المحسوبة تلقائياً (عجز / زيادة / مطابق بالمليم).

#### 🛡️ قواعد أمان Firestore (Firestore Security Rules):
للسماح بالاتصال المباشر وقراءة وكتابة البيانات في Firebase، تأكد من ضبط قواعد Firestore في [Firebase Console](https://console.firebase.google.com/) كالتالي:
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

> **ملاحظة هامة للأمان والاعتمادية:**  
> يدعم النظام **الوضع المحلي الآمن (Local Fallback & Sync)**، مما يعني أنه في حال انقطاع الإنترنت أو وجود قيود على القواعد، يستمر البرنامج في العمل بكامل كفاءته وسرعته ويحفظ كافة المعاملات والـ 18 خط في ذاكرة المتصفح دون أي تعطل للكاشير!

### 🚀 كيفية تشغيل المشروع:
1. افتح المجلد في المتصفح عن طريق تشغيل خادم محلي، مثلاً عبر VS Code Live Server أو بتنفيذ:
   ```bash
   npx serve .
   ```
   أو بفتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome / Edge / Safari).
2. اختصارات لوحة المفاتيح السريعة:
   * **`F2`**: فتح نافذة تسجيل عملية سريعة.
   * **`F3`**: الانتقال لشاشة المسح الضوئي (Scanner).
   * **`Esc`**: إغلاق أي نافذة منبثقة.
   * **`Ctrl + V`**: لصق اسكرينة فوراً في خزنة الإيصالات.
